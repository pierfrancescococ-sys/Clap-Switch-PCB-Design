# Original fabrication files

`Gerber_PCB4_2026-05-09_original-JLCPCB-order.zip` is an unchanged copy of the **Gerber archive recovered from the actual JLCPCB fabrication order**. It includes copper, solder-mask, silkscreen, outline and plated-through drill files, together with ancillary export files.

**This is the as-ordered manufacturing snapshot.** It is not a fresh Gerber export from the later EasyEDA project. The archive is supplied for technical inspection and education, not a blanket authorization to fabricate and operate the design in any electrical environment. Refer to [`../docs/design-revision-notes.md`](../docs/design-revision-notes.md).
