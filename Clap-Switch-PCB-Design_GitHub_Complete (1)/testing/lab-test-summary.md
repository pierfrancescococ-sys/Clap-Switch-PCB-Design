# Laboratory functional test summary

**Source:** Equipment Design and Material Engineering project report (pp. 16–18). This document summarizes the reported measurements and observations; it is not a new test campaign.

**Setup:** assembled, through-hole Clap Switch PCB, AXIOMET AX-3005D bench DC power supply set to approximately **10.3 V**, electret microphone exposed to handclaps.

**Observed result:** each recognized handclap changed relay state. Initially the relay switched but the LED stayed off. After reversing LED orientation, the LED correctly reflected the output switching state. The final laboratory test was reported successful.

**Not measured/documented:** quantified acoustic response range, sensitivity, noise rejection / false triggering, endurance, isolation strength, mains-rated operation, or formal safety certification.
